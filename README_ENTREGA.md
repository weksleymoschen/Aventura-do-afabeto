# Aventura do Alfabeto — WM Jogos Educativos

Pacote de entrega preparado para Netlify e GitHub Pages.

## Revisões de entrega
- botão voltar reduzido a uma seta funcional;
- removidas sobreposições de nome/contador nas fases;
- imagens configuradas para não esticar nem deformar;
- botão de música funcional;
- início protegido: exige nome e personagem;
- seleção de avatar mantida clicável;
- Fase 1 mantém a dinâmica de uma única associação correta por atividade;
- progressão preservada para as fases seguintes;
- estrutura pronta para hospedagem estática.

## Publicação
Netlify: envie a pasta inteira ou o ZIP.
GitHub Pages: publique o conteúdo desta pasta na raiz do repositório.
