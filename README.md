# Aventura do Alfabeto

Jogo educativo para crianças de 4 a 6 anos.

- 5 fases × 5 atividades = 25 atividades
- imagem de associação em todas as atividades
- transição visual entre as fases
- nome editável apenas na abertura
- 6 avatares na abertura; depois apenas o avatar escolhido
- música, estrelas, progresso, acerto/erro e confetes
- sem backend e com caminhos relativos

## Publicar no GitHub Pages
Envie todos os arquivos para a raiz do repositório. Depois acesse **Settings > Pages > Build and deployment**, escolha **Deploy from a branch**, selecione `main` e `/ (root)` e salve.
